# Interaction system

Every consequential interaction follows: **scope → evidence → proposal → impact → author decision → provenance**. The system does not jump from request to mutation.

Findings expose severity, explanation, current source, conflicting source, assumptions, and affected records. Available decisions are accept, partial accept, edit, reject, retry, compare, create alternate, create revision task, or propose canon. The exact set depends on authorization and operation.

Google imports follow select → detect → map → normalize → validate → preview → confirm → background result. Authentication and integration consent are separate. Editor saves use optimistic revision numbers; stale writes return a conflict instead of overwriting newer prose.

Controls are keyboard operable, labeled by purpose, and expose selected/expanded state. Motion supports understanding and respects `prefers-reduced-motion`.
