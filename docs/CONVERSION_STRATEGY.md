# Conversion strategy

The conversion story moves from emotional recognition to operational proof: fragmented story memory → connected manuscript → cited continuity → language and format fit → Google migration path → privacy boundary → founding access.

Public pricing uses `founding-access` mode from centralized configuration because checkout and approved prices are not implemented. No fake urgency, discount, trial, customer, testimonial, or usage metric is shown.

The event contract must exclude private content. Allowed properties are route, locale, regional variant, anonymous session, consent state, campaign parameters, experiment assignment, control identifier, and coarse completion state. Intended events include homepage view, hero demo start/completion, graph interaction, finding opened, suggestion explored, language switch, Google demo opened, pricing view, CTA click, signup start/completion, blog view, and template download. No analytics provider is currently wired; the contract is architectural documentation, not an implementation claim.
