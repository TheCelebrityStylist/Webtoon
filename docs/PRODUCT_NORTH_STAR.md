# Product north star

PanelForge is private writing software. It helps writers build, understand, draft, and revise long stories without losing continuity, voice, intent, or ownership. It is not a reader network, marketplace, public publishing service, or generic chat wrapper.

The canonical workflow is idea → premise → story bible → characters → world → chronology → plot → chapters/episodes → scenes → beats → draft → review → revision → manuscript → export. Author text and accepted canon remain distinguishable from proposed alternatives and AI output.
