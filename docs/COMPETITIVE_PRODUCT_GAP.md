# Competitive product gap

Checked 2026-07-14. **Verified:** Campfire describes modular manuscript, character, outline, map, culture, species, language, religion, and timeline tools on its [official product page](https://campfirewriting.com/write/fantasy). **Unverified:** detailed current Foretelling capabilities; sufficiently specific first-party documentation was not available, so no absence claim is made.

| Common limitation | Proposed capability | Material improvement |
| --- | --- | --- |
| Disconnected notes | Project story graph | Scenes cite their constraints. |
| AI loses context | Minimal context with IDs | Writers see the evidence. |
| Static characters | Time-aware state/knowledge | Checks use the right story point. |
| Manual causality | Typed beats and causal edges | Deterministic gaps become visible. |
| Grammar-only revision | Evidence-linked findings | Feedback becomes actionable work. |
| Silent AI edits | Proposed suggestions and decisions | Author text never changes implicitly. |
| Interface-only localization | Writing locale and regional rules | Analysis works in manuscript language. |
| Flat exports | Structured archive and manuscript exports | Planning structure remains portable. |
| Unsafe alternatives | Isolated narrative branches | Experiments cannot corrupt canon. |
| Late continuity discovery | Save-time graph checks | Issues surface during drafting. |

No competitor design, terminology, or proprietary flow is copied.
