# AI context engine

AI is an embedded reviewer, never an autonomous author. The scene-purpose operation retrieves only the selected project, scene and beats, active characters, and world rules. Requests persist operation, locale, context IDs, model, prompt version, result, explanation, and author decision.

Accepting a response records a revision finding; rejecting records dismissal. Neither changes manuscript or canon. Provider failure is explicit; no fake result is substituted. Full prose is never logged.
