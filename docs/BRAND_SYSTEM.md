# Brand system

The single runtime source of truth is `lib/site.ts`. UI code imports `brand` or `site`; it must not repeat the product name, promise, descriptor, marks, or core colors.

## Verbal system

- Working name: Asterism
- Descriptor: Story intelligence for serious writers
- Promise: See the whole story. Change it with confidence.
- Primary action: Start writing
- Intelligence verbs: trace, inspect, compare, cite, propose, decide, branch
- Avoid: magic, effortless bestseller, co-author, guaranteed, instant masterpiece

## Visual system

The palette pairs Void `#080b10`, Paper `#f2f0e9`, Signal `#d9ff43`, Violet `#9d8cff`, and Ice `#9ee7ff`. Dark product canvases reveal relationships; light editorial fields support reading. Signal is reserved for active paths and primary actions. Violet marks proposals and alternate states. Ice marks evidence and external sources.

Typography contrasts an editorial serif for narrative meaning with a restrained sans-serif for controls, evidence labels, state, and metadata. The symbol `✦` is a temporary typographic mark, not a registered logo.

Motion must explain state: tracing a causal path, revealing affected nodes, opening evidence, or changing a lens. All motion has a reduced-motion equivalent. Decorative parallax and ambient motion are excluded.

## Composition

Marketing pages use eight composition families instead of one duplicated template. Product proof appears as an operable control with a deterministic output. Graph motifs represent typed relationships, never arbitrary decoration. Empty states explain what evidence is absent and what action creates it.
